# Design contract

## Options and selection
Visual artifact links for every option; 5–10 count; comparison; source URLs; selected IDs or exact user override; combination rules.

## Product identity
Audience, desired impression, reference/anti-reference reasons and content voice.

## Tokens
Actual semantic colors, type scale, spacing, widths, radius, elevation and motion; contrast evidence.

## Components and states
Scope-specific kit; responsive behavior; default/hover/focus/active/disabled/pending/error/empty/success.

## Brand assets
Logo/wordmark, favicon, OG when public; source/licensing and export paths.

## Verification
Reference comparison plus actual browser states, mobile and keyboard evidence.
