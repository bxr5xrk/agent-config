# Logo concepts, masters and evidence

## Choose the right medium

- Inspect supplied artwork before judging or editing it. Preserve an approved mark and source; create revised candidates separately. When only a raster is supplied, do not pretend a lost vector source is available.
- For a simple original geometric mark or a repo-native vector identity, author/edit real SVG geometry. Favour a small intentional silhouette, balanced negative space and optical alignment. More intricate is not automatically more distinctive.
- For richer original illustration or raster concept exploration, use the available imagegen skill/tool. For raster edits follow its reference-image workflow; inspect generated results. Tool availability and actual output determine capability; do not promise a feature that is absent.
- Accurate wordmarks should use actual licensed type with deliberate spacing. Verify spelling in the final asset. Generated lettering is a concept until inspected and corrected; do not ship a misspelled name because a mockup looks attractive.
- A PNG inside an SVG wrapper is still a raster. Reconstruct a selected simple concept as editable vector and compare it visually; if faithful vector production is not feasible, label the raster limitation and offer a refined wordmark/appropriate simpler mark within the brief.

Do not copy another company's distinctive symbol, trace gallery examples into a supposedly original logo, or claim trademark uniqueness from appearance. Sources and provenance belong in BRAND.md. A generic library icon may support the UI, but does not become a distinctive proprietary logo merely by recoloring it.

## Explore and refine

Use positioning, audience and selected visual direction. Produce a few genuinely different visual ideas, such as typographic, abstract or concept-derived, only where they fit this brief. Compare actual artwork on a neutral background before decorative mockups. Articulate what the form communicates without inventing elaborate symbolism after the fact.

Inspect silhouette, optical weight, spacing, negative-space holes and similarity to obvious competitors. Refine one meaningful flaw at a time; compare before/after at final use sizes. Choose or recommend a wordmark alone when it works better. A mark should work without gradients, blur, animation or 3D to make it readable; those can be optional expressive treatments of an already functional identity.

## Build a usable asset set

Scope to intended use: editable master, horizontal lockup or wordmark, standalone small mark where needed, monochrome and reversed variants, favicon and public social image. Do not generate redundant exports for hypothetical channels. For a web logo, inspect SVG viewBox, cropping, dimensions, external dependencies and weight. Avoid embedded scripts or external network references in assets. Keep editable typography source/font identity; an outlined export can improve portability when licensing permits, but do not fake outlines.

Use suitable accessible rendering in product code: linked brand has an accessible home/name label; decorative repeated logo has empty alt or is hidden from assistive technology; prevent redundant announcements. Set image dimensions to avoid layout shift. Do not bake critical landing copy into the logo artwork.

## Mandatory visual checks, when producing a logo

Render and inspect the selected artwork, not only its source. Use a simple in-project browser proof sheet or available image tools:

- Actual intended header size and a larger silhouette view, with realistic adjacent navigation.
- Favicon at **16 and 32 CSS px** and app/avatar size if applicable. A detailed wordmark usually needs a simplified small mark. Record the smallest size that actually reads; do not assign an untested universal minimum.
- Light and dark backgrounds, one-color black/white, transparency edges and sufficient surrounding space. Clear-space rules derive from this mark and actual layout tests.
- Exact name spelling, font substitution, kerning and relevant glyph coverage. Check export rendering separately from the authoring preview.
- Recognizable form without motion, shadows or gradients; mobile clipping/overlap; consistent alignment across variants.

Record pass/fix/pending per check in BRAND.md. These checks support craft and production readiness; they do not objectively prove that a logo is excellent. User selection and real audience feedback remain separate evidence. Do not claim a designer-level guarantee or that a single test demonstrates universal naming/logo ability.

Reference, reviewed 2026-09-05: [Mozilla's brand usage](https://mozilla.design/mozilla/logo-usage/) is an example of actionable spacing, size and variant guidance. Its specific rules apply to its own brand, not every logo.
