# Minimal brandbook

## Status and fixed inputs
Version/date; supplied/created name and assets; approved/delegated/provisional status; selected name/logo/UI IDs and exact user constraints. Repository slug is separate from display name.

## Positioning and name
Audience and situation; promise and evidence; useful difference; character and anti-traits; exact name spelling/capitalization; pronunciation/languages when relevant. Naming rationale and dated screening results with URLs; unchecked items stay unchecked.

## Voice in use
Real headline, CTA, success and recovery copy; terminology and tone; examples to avoid. No fabricated claims or endorsements.

## Logo
Visual examples and editable master/export paths; wordmark/lockup/small mark; light/dark and monochrome variants as needed; measured minimum size and clear space; permitted backgrounds; misuse examples. Source/license/font provenance and any raster limitation.

## Color and typography
Actual palette values and semantic roles; allowed text/background pairs with measured contrast; state colors and non-color cues. Font families/weights, hierarchy, fallbacks, language coverage, sources/licenses and loading choice. Link the implementation's token source through DESIGN.md.

## Art direction
Photography/illustration/icon rules, examples and avoided treatments; layout rhythm and bounded motion character. Link selected UI directions, DESIGN.md and landing review when applicable.

## Proof and limitations
Artwork renders at header and 16/32 px favicon sizes; light/dark/monochrome; exact spelling and export/font checks; mobile context. Record actual result and fix for each applicable check. Separate human feedback, agent assessment and unavailable evidence.
