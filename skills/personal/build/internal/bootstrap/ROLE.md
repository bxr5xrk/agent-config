# Internal project bootstrap

Use only when an agreed or explicitly delegated brief needs a new project directory. Existing projects are edited in place. The build owner invokes this procedure; it is not another user-facing skill.

1. Read the [adopted defaults](../../references/defaults.md), brief and canonical design/brand decisions. Select only the necessary `web`, `api` or `fullstack` profile. The transport examples do not imply a need for a database, authentication or a separate API.
2. Prepare inputs under the current workspace's `work/bootstrap/<project>/`: [state.json](assets/documents/state.json) and the actual agreed `BRIEF.md`. For a selected visual direction include its actual `DESIGN.md` and selected artifact IDs. An existing approved design counts; variants have no mandatory count. Use `user_override` with the exact provenance when the user delegated the visual choice. Record accepted/delegated intent honestly; the script cannot validate consent.
3. If canonical document names differ, copy their approved contents into those input filenames and record their source paths. Include actual `BRAND.md`, `ANALYTICS.md`, `HANDOFF.md` or `LANDING-REVIEW.md` only as applicable. Carry referenced visual assets and reconcile links; a copied filename alone does not preserve its dependencies.
4. Run `python3 <absolute-bootstrap>/scripts/scaffold.py <absolute-new-destination> --name <ascii-slug> --profile <profile> --state <absolute-state.json>`. Preserve the exact Unicode display name separately from the package slug. The generator refuses existing directories/symlinks and missing/placeholder required documents.
5. Inspect the generated files. Keep canonical project records in `docs/project` and create or update root `design.md` as a pointer through the [context contract](../../references/context.md). For an API-only project record visual work as not applicable. Avoid a second independently maintained design contract.
6. Run `pnpm install --frozen-lockfile`, then `pnpm verify`, using the available supported runtime. Retain the included profile lockfile; no Git initialization or commit is required. The bundled dependency snapshot was reviewed 2026-09-04; verify compatibility before reuse, and distinguish generator tests from application/runtime validation.
7. Hand the appropriate surface to designer/frontend/backend. Replace sample pages and echo/status examples with the first real journey; add only required persistence/integrations. Public `noindex` remains until SEO metadata and visibility are intentionally configured and checked. Use the build review and closeout procedures for the delivered product.

Fullstack development uses the API on 3001 and web on 3000. Run `pnpm --filter @starter/api dev` and `pnpm --filter @starter/web dev` in separate sessions; configure the web's non-secret `API_ORIGIN` from its example. Next reads its env file; the API expects exported environment variables. Inspect manifests and current output before assuming those commands succeeded.

Relocation regression check: `python3 -B <absolute-bootstrap>/scripts/test_scaffold.py`. It checks generator profiles, record preservation and refusal behavior; it does not certify the finished product or live providers.
