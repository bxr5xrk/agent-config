# Refactoring UI: що застосовано

Джерело: локальний примірник *Refactoring UI* Адама Ватана і Стіва Шогера, 218 PDF-сторінок. Переглянуто зміст усіх розділів, ключові текстові частини та візуальні приклади на сторінках 31, 54, 84, 103, 143, 177, 203, 207; це не твердження про детальне візуальне читання кожної сторінки.

| Принцип | Практичне рішення спеціаліста |
|---|---|
| Почати з корисної функції, с. 7–13 | Спочатку реальний сценарій і контент, потім shell та прикраси |
| Характер і обмежений набір значень, с. 17–28 | У `design.md` зафіксовані характер і посилання на token source; нові довільні значення потребують причини |
| Візуальна ієрархія, с. 30–54 | Одна зрозуміла первинна дія; другорядний текст не конкурує з нею, але залишається читабельним |
| Відступи й ширини, с. 56–86 | Споріднені елементи групуються; сторінка не розтягується лише тому, що є вільний екран |
| Типографіка, с. 88–116 | Реальні довжини, baseline alignment, окрема адаптація headline/body на вузькому viewport |
| Колір і глибина, с. 119–172 | Семантичні ролі, перевірений contrast, послідовна elevation; декоративні тіні не обов’язкові |
| Зображення, с. 174–190 | Кадрування й контраст перевіряються з реальними або крайніми uploaded assets |
| Завершеність, с. 192–214 | Empty/error/pending — повноцінні екрани, а не забуті стани після красивого happy path |

Книжка добре доповнює Impeccable/Emil фундаментом композиції. Вона не закриває сучасні browser/framework APIs, весь WCAG 2.2, поведінку анімацій у часі, продуктову аналітику чи перевірку реального сценарію.

Важливі межі: порада про labels на с. 41 прямо не стосується форм; заголовок про semantics на с. 52 — про візуальний пріоритет кнопок. Не переносимо це як дозвіл прибирати accessible labels/semantic HTML. На с. 142 використано неточне скорочення про ~18px: актуальна WCAG-межа великого тексту — 18pt або 14pt bold, а не будь-які 18px. Кількість відтінків, HSL, певні шрифти й відступи — авторські евристики, не універсальні стандарти.

У пакет включено власний стислий синтез; книгу та її сторінки не перепаковано. Актуальні нормативні значення звіряються з [WCAG 2.2](https://www.w3.org/TR/WCAG22/).
