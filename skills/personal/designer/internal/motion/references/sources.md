# Motion sources and limits

Inspected 2026-09-05. Instructions here are an original synthesis; no upstream animation recipe or paid component is bundled.

- [Emil Kowalski's skills](https://github.com/emilkowalski/skills/tree/d23d7f88a2e21c9e4b1418c7abe420f5c1052ba7), all 19 skill/reference Markdown files, [MIT](https://github.com/emilkowalski/skills/blob/d23d7f88a2e21c9e4b1418c7abe420f5c1052ba7/LICENSE): valuable gesture, frequency, implementation and audit examples. Fixed timing/input prohibitions conflict with some recipes; keep the rationale and test the context. Native/Swift material is not a verified web API guide.
- [Impeccable](https://github.com/pbakaus/impeccable/tree/8dac6ae7e020c43ab10ce9b41939f6fd42627b96), canonical entrypoint, every reference and four agents, [Apache-2.0](https://github.com/pbakaus/impeccable/blob/8dac6ae7e020c43ab10ce9b41939f6fd42627b96/LICENSE): useful project continuity and review contracts. Its fixed aesthetic gates, exploration rounds and runtime are not inherited. Its file/screenshot reviewer does not itself establish temporal behavior.
- [Jakub Krehel's skills](https://github.com/jakubkrehel/skills/tree/267330e1adfc66a718fb65fa6918c1f06d0a689e), selected interface, accessibility, motion, stress and variant modules, [MIT](https://github.com/jakubkrehel/skills/blob/267330e1adfc66a718fb65fa6918c1f06d0a689e/LICENSE): useful domain ownership, actionable evidence and real-component stress cases. Exact scale/easing values are house style.
- [Rauno's interaction observations](https://rauno.me/craft/interaction-design): useful ways to inspect continuity, gestures and small interaction details; observations are not universal standards.
- [Anime.js scope docs](https://animejs.com/documentation/scope/) and [MIT license at 01b81be1](https://github.com/juliangarnier/anime/blob/01b81be1df6843ccfe0a71c0699a746bf740dd77/LICENSE.md): official integration reference. [Motion performance docs](https://motion.dev/docs/performance): version/browser-sensitive acceleration limits.
- [Kinetics](https://kinetics.colorion.co/): useful live spring examples and tunable stiffness/damping references. Copying a spring or AI prompt does not establish fit; derive the motion job first, test interruption and reduced motion, then tune in the rendered product.
- [Motion Primitives](https://motion-primitives.com/docs) and its [MIT license](https://github.com/ibelick/motion-primitives/blob/main/LICENCE.md): useful reusable Motion/Tailwind implementations when that stack already fits the project. The project is beta; inspect current source/API and adapt its semantics, focus behavior, performance and motion contract instead of importing a demo blindly.
- [Aceternity component catalog](https://ui.aceternity.com/components) and [license](https://ui.aceternity.com/licence): visual patterns require per-component interaction review and permission checks. For example, documented hover pause on [infinite moving cards](https://ui.aceternity.com/components/infinite-moving-cards) alone does not establish keyboard/touch control or reduced-motion behavior.

See [asset boundaries](../../../references/sources-and-assets.md) before copying. Keep paid assets in permitted project use; global lessons capture scoped reasoning, not licensed source archives. Verify current official APIs rather than treating this inspection date as future compatibility evidence.
